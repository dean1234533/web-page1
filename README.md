# DB's Workouts: early landing page

**A single-page landing site for a mobile personal trainer in East London, with a free consultation call to action, PT services, bespoke workout plans, group training, and locations.**

![HTML5](https://img.shields.io/badge/HTML5-E34F26?style=flat-square&logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?style=flat-square&logo=css3&logoColor=white)

> **This is an early learning project.** The current production site is
> [dbworkouts.co.uk](https://dbworkouts.co.uk)
> ([source](https://github.com/dean1234533/index.html)).

---

## Features

- A free personal training consultation call to action
- Personal training services and sessions
- Bespoke workout plans
- Small group and pairs training
- Training locations

## Tech stack

A single `index.html` file of HTML and CSS.

## Run locally

```bash
git clone https://github.com/dean1234533/web-page1.git
cd web-page1
open index.html
```
